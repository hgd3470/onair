AI는 초안과 1차 의견을 내고, 결정은 사람이 한다. 단계마다 내가 정하는 것 하나, 막힐 때 볼 질문 셋, 실제 대본에서 고른 예시가 있다.

1단계 · 대본 담당

대본 쓰기

운전 중인 사람이 첫 문장을 듣고 끝까지 들을 이야기인가

막힐 때 볼 질문

  1. 제목만 듣고 장면이 떠오르나? 강의 제목처럼 들리면 다시 쓴다.
  2. 첫 문장이 질문이나 의외의 장면으로 시작하나? 배경 설명으로 시작하면 두 번째 문장과 순서를 바꿔 본다.
  3. 화면 없이 귀로만 들어도 따라오나? 소리 내어 읽고 숨이 차는 문장은 나눈다. 250~450자.

제목

살아 있는 제목양말 대기실, 맞는 번호 반대 방향짧고, 무슨 일인지 궁금하다. 일상 장면 하나를 비튼다.
힘이 빠지는 제목AI 시대 콘텐츠의 제작과 IP 확장, No로 지키는 시간과 에너지강의 제목처럼 들리고, 영문은 음성으로 읽으면 어색하다.

첫 문장

귀가 열리는 첫 문장빨래를 갰는데, 양말 다섯 짝이 모두 서로 모르는 사이였어요.장면과 반전이 한 문장에 있다.
그냥 지나가는 첫 문장짧은 이야기를 하나 만들었다고 해 볼게요.아직 아무 일도 일어나지 않았다. 궁금한 것이 없다.

AI와 나눠 맡기

AI에 맡길 것
  • 양식 맞추기, 숫자·영문을 한글 읽기로
  • 소재 후보 여러 개, 제목 후보 열 개
내가 볼 것
  • 제목 하나 고르기, 첫 문장 고치기
  • 소리 내어 읽기, 출처 링크 열어 보기
2단계 · 검수 담당

대본 검수

이 대본을 내보냈을 때 틀린 말이나 남의 글 때문에 문제가 생기지 않는가

막힐 때 볼 질문

  1. 사실 문장마다 출처에 실제로 있나? 출처 링크를 열어 숫자와 연도를 대조한다.
  2. 원천 등급이 '허락 전 금지'는 아닌가? '사실만 참고'인데 문장을 그대로 옮기지 않았나?
  3. 혐오·차별, 의료·투자 단정, 실존 인물 비방이 없나?

예시

출처로 확인되는 질문형훈민정음은 천사백사십삼 년에 만들어졌을까요, 천사백사십육 년에 만들어졌을까요?두 연도가 각각 무엇인지 출처에서 바로 확인할 수 있다.
다시 볼 것첫 공연을 마치고, 말없이 앉았던 저녁 본문 874자사실은 문제없어도 기준(250~450자)을 크게 넘는다. "수정 필요"로 돌려 둘로 나누거나 줄이게 한다.

내가 볼 것

3단계 · 음성 담당

목소리 배정

이 이야기를 누가 말해야 듣는 사람이 믿고 계속 듣는가

막힐 때 볼 질문

  1. 화자는 몇 살쯤이고, 웃긴 썰인지 잔잔한 사연인지 정보 전달인지?
  2. 장르 담당이 정해져 있나? 성경은 성호, 광고는 은채, 고전·역사는 주하, 시사·정책·법은 필재.
  3. 한 목소리가 전체의 30%를 넘지 않나?

예시

본문에서 근거를 댄 배정첫 출근, 이름이 두 개 → 박창수"닉네임 '제이'가 옆자리 동료였다는 반전으로 웃기는 직장 썰이다." 분위기를 근거로 규칙 기본값(다은)을 바꿨다.
근거가 빈 배정장르만 보고 기본값 그대로규칙표만 따르면 같은 목소리가 몰리고, 웃긴 썰도 잔잔하게 들린다.

4단계 · 관리자

음성 만들기 · 들어 보기

이대로 운전자에게 내보낼까

막힐 때 볼 질문

  1. 숫자·영문·고유명사를 제대로 읽었나? 연도와 이름부터 듣는다.
  2. 문장 사이가 끊기거나 너무 빠른 곳은 없나?
  3. 첫 오 초에 분위기가 대본과 맞나? 웃긴 썰이 너무 진지하게 들리지 않나?

5단계 · 모두

팀 API 게시 뒤

들은 사람이 다음 편도 들었나, 그래서 다음엔 무엇을 쓸까

막힐 때 볼 질문

  1. 끝까지 들은 편과 중간에 넘긴 편은 제목과 첫 문장이 어떻게 달랐나?
  2. 어떤 상황(출근길, 아이 동승, 밤 운전)에 맞는 편이 비어 있나?
  3. 같은 소재를 다른 목소리로 내면 반응이 달랐나?

예시는 지금 팀 API에 게시된 37편에서 AI(Claude)가 골랐고, 팀이 아직 확인하지 않았다. 각 단계의 상세 규칙은 대시보드에서 받는 꾸러미의 프롬프트 파일에 있다.
