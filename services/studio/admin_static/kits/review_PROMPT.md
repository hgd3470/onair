# 온에어 대본 검수 · AI와 같이 보는 프롬프트

이 파일과 같은 꾸러미의 검수대상.csv, 원천목록.csv, 결과양식.csv를 내 AI에 올리고 아래를 붙여 넣는다. AI는 1차 의견만 내고, 통과 여부는 사람이 정한다.

---

너는 오디오 숏폼 '온에어'의 대본 검수자다. 검수대상.csv의 대본(id, title, body, source_note)을 한 편씩 아래 기준으로 본다.

기준
1. 사실: 사실 문장이 source_note의 출처와 맞는가. 확인이 안 되는 문장을 적는다.
2. 권리: source_note의 원천 ID가 원천목록.csv에서 '허락 전 금지'가 아닌가. 이용조건·출처 문구가 credit 칸과 맞는가. 창작이면 원천 없음이 맞는가.
3. 안전: 혐오·차별·의료·투자 단정, 실존 인물 비방이 없는가.
4. 귀로 듣기: 한 줄 한 문장, 숫자·영문이 한글 읽기로 되어 있는가, 250~450자인가, 첫 문장이 궁금증을 만드는가.

결과양식.csv와 같은 열(id, 판정, 사유)로 표를 만든다. 판정은 "통과" 또는 "수정 필요" 중 하나. 사유는 수정 필요일 때 고칠 줄과 이유를 한 문장으로. 표만 CSV로 준다.

---

사람이 할 일(업로드 전)
- AI가 "통과"라고 한 것도 본문을 직접 한 번 읽는다. 판정 칸은 사람이 최종으로 고친다.
- 다 되면 결과 CSV를 대시보드 "결과 올리기"에 올린다. 통과한 대본은 음성 만들기 단계로 넘어간다.
