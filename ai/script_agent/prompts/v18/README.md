주요 보완은 창작의 특징적 장면 조합 재구성, 추상적인 상태의 실제 기능 설명, 위험 지속 미화 및 결말 반복 방지, 조건·추정 강도·수치 대상·인과 연결 검증, 제목 수치와 청취 혼동 점검, 원문 인용의 정확한 문자열 보존이다. 지리적으로 포함된 장소를 간단히 요약한 경우와 사실 범위를 넓힌 경우도 구분한다. 모델·effort·수정 예산·스키마·검증 코드는 이 프롬프트 실험을 위해 변경하지 않는다.

사용자 요청에 따라 제출용43편 모두 이 버전으로 새로 생성한다. 이전 버전의 유지 후보를 제출본에 섞지 않는다. 확인한 대본별 편집 요구를 기존 editorial_brief 계약으로 함께 전달하므로, 실제 결과는 일반 프롬프트 단독 효과와 구분해 보고한다. 생성·검토 상태는 그대로 보존하며 사람 승인이나 TTS 통과로 바꾸지 않는다.
