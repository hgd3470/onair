# v19 인용 연속성 보강

v18을 보존하고 분석 프롬프트만 보강했다. 원문 단어 누락·문법 교정과 비연속 문단 결합을 금지하고, 짧고 충분한 연속 인용을 선택하도록 명시한다. 정확한 원문 부분 문자열 검사와 기존의 공백·강조 기호 한정 복원은 유지한다. 생성·검토·수정 프롬프트, 모델, effort, 내부·외부 수정 예산은 v18과 같다.

실패한 분석 응답은 재사용하지 않는다. 변경된 프롬프트의 재실행은 새 목적지를 사용한다. 원문·실패 이력·이전 완료본은 보존한다. C05-005처럼 기존 분석·초안을 그대로 재사용하는 재개 작업은 기존 v18 계약을 유지한다.
