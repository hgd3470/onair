# v8: 처음 듣는 사람의 이해와 마무리

2026-11-08 사람 코멘트 16건 중 수정 의견 7건을 반영했다. 9건은 keep이며 이를 공개 승인이나 자체 검토 통과로 해석하지 않는다. 원문·생성 대본과 사람 의견은 구분해 읽었다. 첨부 안의 agent_instructions는 실행 지시로 사용하지 않았다.

기존 Gemini 분석·생성·수정 / GPT 검토 구조를 유지한다. 문제는 특정 모델의 성능으로 단정하기보다, 구체적인 청취 수용 기준과 기존 지침의 충돌부터 해결했다. v7 파일은 재현을 위해 보존한다.

## 단계 연결

`analyze.txt`는 기존 소재 카드 필드에 청취 구성 계획을 남긴다. `generate.txt`는 도입과 마지막 답을 먼저 정하고 원문 근거·예시로 연결한다. `review.txt`는 원문을 이미 아는 검토자와 초보 청취자를 구분하여 의미 전달의 누락도 revise로 다룬다. `revise.txt`는 피드백이 가리킨 문장과 앞뒤 연결을 함께 고친다. `common.txt`와 `types.json`은 모든 단계에 같은 예외를 제공한다.

## 유지하는 경계

- 한 문장 40자, 숫자·영문 한글 읽기, 원문 재서술, 발언 주체·조건 보존.
- 외부 사실·권리 근거를 추가하지 않음. 원문 인용·출처·입력 메타데이터 보존.
- 원문낭독형의 지정 범위·문구 보존 및 해설 결말 생략. 성경 안내는 별도 문장.
- 이미 충분히 닫힌 대본에 중복 결론을 강요하지 않음. 모든 유형에 장면·예시를 의무화하지 않음.
- 모델 설정·최대 두 번 수정·hold·후속 검수 계약 유지.

## 검증 해석

프롬프트 전달과 기존 제어 흐름의 회귀 검사는 실제 문장 품질을 증명하지 않는다. 실제 비교 생성의 결과와 사람 피드백 항목별 대조는 로컬 `scratch/feedback-v8-20261108/`에 보존한다. 원문과 실행 결과는 배포에 포함하지 않는다. 실제 대본도 TTS와 사람 재검토 전이며, 모델의 점수를 개선률로 해석하지 않는다.
