# v13 — 사건 순서 보존과 표현 복제 구분

사용자 피드백: 원문과 사건 순서가 같다는 이유만으로 C01을 보류하는 것은 과도하다. v12 파일은 변경하지 않고 v13의 common/review/types에 판정 경계를 명시했다.

시간·인과 순서와 핵심 사건 배열은 유지할 수 있다. 표현 복제를 지적하려면 문장 번호와 대응 원문 표현을 근거로 제시한다. 사건 순서만으로 수정·보류·감점을 주거나 재배열·새 사건 창작을 강제하지 않는다. 실제 긴 구절·고유 표현·문장 구조 복제, 사실 왜곡, 근거 없는 창작, 결말 중복, 40자·한글 읽기 검사는 유지한다. 검증 코드의 표면 유사도 기준은 변경하지 않았다.

C01은 사용자 요청으로 결말 요약 14번 한 문장만 직접 삭제하고 원래 15번과 근거표를 14번으로 옮긴다. 자동 수정 횟수 2회는 유지한다. 재검토는 별도 로그·버전에서 실제 검토 모델을 한 번 호출하며 자동 재생성·수정은 하지 않는다. 결과는 scratch/c01-review-policy-v13-20261108/에 기록한다. 모델 판정은 사람 승인·TTS·권리 승인과 구별한다.

실제 결과: C01은 삭제 전15문장→삭제 후14문장, 1.0.2+editorial.1. 첫 검토가 완료된 삭제 메모의 과거 문장 번호를 현재 번호로 혼동해, 대본을 바꾸지 않고 메모를 별도 감사 기록에만 남겨 재검토했다. 최종 검토는 순서/중복 지적 없이 실제 귀가 장면으로 끝내라는 새 의견으로 revise/hold다. 이 의견까지 자동 해결하거나 pass로 덮어쓰지 않았다. 원본 및 실패 기록 보존, 회귀149개 통과.
