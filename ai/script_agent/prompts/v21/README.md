# v21: 사건 중심 뉴스 오프닝과 내부 출처 분리

v20을 보존한다. 뉴스 인계 v3와 공통 편집 요구사항은 보도 매체를 내부 기록으로 한정하고 실제 발표 기관·날짜·사건으로 시작한다. 한국시간 안내와 해요/죠체를 금지하며 40~50대 직장인에게 중요한 검증 사실을 우선한다. 일반 비뉴스/원문낭독형의 원문 보존 규칙은 유지한다. 모델·수정 예산은 그대로이며 새 목적지에서 실행한다.

실제 검토에서 도입의 구체성, 수치의 분모·비교 기준, 합의와 의결의 관계, 목표 연도와 확정 시점의 구별 및 유월/시월 낭독을 보강했다. 최초 데모 프롬프트와 최종 프롬프트를 수집기 research/editorial-v21-20261112/first-pass-prompts 및 final-prompts로 각각 보존한다. 변경된 프롬프트로 과거 체크포인트를 재개하지 않는다.
