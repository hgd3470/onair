## 제작·검수 상태

- manifest는 제작 대상을 고르는 목록이며, 기존 CLI가 자동으로 읽는 설정 파일은 아니다. 아래 예시처럼 경로를 추출해 `ingest`에 전달한다.
- 기존 TTS·게시 이력이 있는 원고도 포함된다. 따라서 모든 원고를 일괄적으로 ‘TTS 전’이라고 표시하지 않는다. 실제 작업·검수 상태는 운영 중인 제작 DB와 카탈로그에서 확인한다.
- `target_sec`는 목표 시간이며 실측 길이가 아니다. 이번 정리에서 TTS·DB 등록·사람의 청취 검수·공개 승인을 실행하지 않았다. 기존 음원의 길이를 수정 원고의 실측값으로 사용하지 않는다.
- 출처·사실/창작 구분·이용 범위는 각 원고 제4절을 기준으로 한다. 접근이 제한된 방송·영상 후보는 사실 근거로 사용하지 않았다.

## 일반 대본만 등록하는 예시

저장소 루트에서 실행하는 Bash 예시다. 파이프라인 의존성이 설치된 Python 환경을 사용하고, `WORK`는 담당자가 사용하는 제작 작업 경로로 바꾼다. 이 명령은 대본 등록만 수행한다.

```bash
export PYTHONPATH="$PWD/ai/content/src"
export WORK="/path/to/production-work"
python - <<'PY'
import json
import os
import subprocess
import sys
from pathlib import Path

root = Path.cwd()
manifest = root / "content/scripts/_index/production-manifest.json"
items = json.loads(manifest.read_text(encoding="utf-8"))
paths = [(root / item["script_path"]).resolve() for item in items]
if len(paths) != 37 or len(set(paths)) != 37:
    raise ValueError("Expected 37 unique production scripts")
if any(not path.is_file() for path in paths):
    raise FileNotFoundError("A production script is missing")
subprocess.run(
    [sys.executable, "-m", "teum_content", "ingest",
     *map(str, paths), "--work", os.environ["WORK"]],
    cwd=root / "ai/content",
    check=True,
)
PY
```

`content/scripts/*.md` 전체 등록이나 기존 `run-pipeline-6.sh`는 P01까지 포함할 수 있으므로 이번 선정 목록을 적용하는 예시로 사용하지 않는다. 위 예시는 기존 DB의 P01을 삭제·비활성화하지 않는다. TTS 작업을 만들기 전에는 해당 DB의 전체 대기 목록도 확인해야 한다.
