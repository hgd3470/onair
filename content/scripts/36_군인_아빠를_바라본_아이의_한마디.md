## 2. 낭독 본문

```text
돌아오는 차 안에서 아내가 아이의 말을 전해 줬어요.
오늘 아빠가 멋있었다고 했대요.
직업군인으로 오래 일한 한 아버지가 남긴 익명 사연이에요.
그는 가족 모임에서 자기 직업과 생활에 대한 평가를 여러 번 들어 왔다고 해요.
어디에 사는지, 돈은 얼마나 버는지.
그동안은 불편해도 넘겼죠.
그런데 그날은 아이에 대한 말까지 이어졌어요.
아버지는 처음으로, 그런 식으로 말하지 않았으면 좋겠다는 뜻을 분명히 전했어요.
집으로 돌아오는 길에 차 안은 조용했어요.
그는 아내가 어떤 마음인지 몰랐죠.
그때 아내가 입을 열었어요.
아이에게는 아빠가 가족 앞에서 자기 생각을 말한 모습이 남았던 거예요.
어른들 사이에서 무슨 평가를 받았는지보다, 아버지에게 오래 남은 건 아내를 통해 전해 들은 그 한마디였어요.
오늘 아빠가 멋있었다는 말이요.
```

## 4. 출처와 작성 범위

[원본에 기록된 소재 출처 1](https://www.instagram.com/p/Detbh_2I0A2/)

초기 데모의 최신 실제 낭독 대본 제2절, 관리번호 **E04**, 「군인 아빠를 바라본 아이의 한마디」를 선별 이관하고 한국어 낭독용 문장 경계를 정리했다. 원본 관리번호와 소재 출처는 이 절에 유지했다.

원본 제작 메모: 직업군인의 익명 사연 각색. 말다툼의 비하 표현은 생략하고 아내가 아이의 반응을 전한 순서를 보존. 진위와 이용허락 미확인.

이번에는 원게시물·연구·방송의 사실성이나 이용허락을 재검증하지 않았다. 익명 사연은 전해진 이야기이며 확인된 실화나 새 창작으로 바꿔 표시하지 않는다. 가정 예시는 실제 성과로 제시하지 않는다. 이번 이관은 현재 서비스의 공개 승인을 뜻하지 않는다.

기존 데모 음원 `story-e04`의 길이는 55.484초이며 파일 해시만 대조했다. **편집한 현재 대본의 실측 길이가 아니며, 해당 음원을 현재 원고의 제작 완료 음원으로 연결하지 않는다.** 원본 데모 파일은 유지했다.

## 5. 연출·청취 확인

- 차분한 구어체와 원본의 말투를 유지한다. 화자의 감정이나 직접 인용 여부를 임의로 강화하지 않는다.
- 핵심 회상 질문: 이 원고의 중심 상황과 마지막에 달라진 점은 무엇인가요?

- 원고를 소리 내어 읽을 때 화자가 바뀌는 지점과 질문 뒤를 짧게 쉰다. 목표 시간에 맞추려고 속도를 억지로 높이지 않는다.
- TTS·실제 발음·실측 길이·사람의 청취 검수·현재 서비스의 공개 승인은 미완료다.
