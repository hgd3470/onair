## 2. 낭독 본문

```text
카페에 손님이 몰려오기 시작했어요.
한 카페 직원이 전한 익명 사연이에요.
키오스크 앞에는 어머니와 장애가 있는 아들이 서 있었어요.
아들이 직접 주문하려는데, 조작이 늦어질 때마다 화면이 처음으로 돌아갔어요.
뒤에는 줄이 길어졌죠.
어머니는 그만해 보자며 아들을 달랬고, 아들은 금세 시무룩해졌다고 해요.
그때 뒤에 있던 손님이 괜찮다며 기다려 줬어요.
겨우 주문을 마치고 어머니가 미안하다고 인사를 했는데, 돌아온 부탁이 뜻밖이었어요.
아드님, 제 것도 주문해 주실래요?
다른 손님들도 하나씩 메뉴를 말했어요.
아메리카노, 바닐라라테.
아들은 다시 신이 나서 화면을 눌렀어요.
잠시 전까지 주문을 끝내야 하는 사람이었던 아들이, 이번에는 다른 손님들의 주문을 도와주고 있었던 거죠.
그 모습을 보면서 어머니는 눈물을 흘렸다고 해요.
```

## 4. 출처와 작성 범위

[원본에 기록된 소재 출처 1](https://www.instagram.com/p/DdDbp1TE_IQ/)

초기 데모의 최신 실제 낭독 대본 제2절, 관리번호 **E02**, 「키오스크 주문 일화」를 선별 이관하고 한국어 낭독용 문장 경계를 정리했다. 원본 관리번호와 소재 출처는 이 절에 유지했다.

원본 제작 메모: 카페 직원 시점의 익명 사연을 3인칭으로 재구성. 아들의 나이는 특정하지 않음. 대사는 요지 각색이며 진위와 이용허락 미확인.

이번에는 원게시물·연구·방송의 사실성이나 이용허락을 재검증하지 않았다. 익명 사연은 전해진 이야기이며 확인된 실화나 새 창작으로 바꿔 표시하지 않는다. 가정 예시는 실제 성과로 제시하지 않는다. 이번 이관은 현재 서비스의 공개 승인을 뜻하지 않는다.

기존 데모 음원 `story-e02`의 길이는 62.929초이며 파일 해시만 대조했다. **편집한 현재 대본의 실측 길이가 아니며, 해당 음원을 현재 원고의 제작 완료 음원으로 연결하지 않는다.** 원본 데모 파일은 유지했다.

## 5. 연출·청취 확인

- 차분한 구어체와 원본의 말투를 유지한다. 화자의 감정이나 직접 인용 여부를 임의로 강화하지 않는다.
- 핵심 회상 질문: 이 원고의 중심 상황과 마지막에 달라진 점은 무엇인가요?

- 원고를 소리 내어 읽을 때 화자가 바뀌는 지점과 질문 뒤를 짧게 쉰다. 목표 시간에 맞추려고 속도를 억지로 높이지 않는다.
- TTS·실제 발음·실측 길이·사람의 청취 검수·현재 서비스의 공개 승인은 미완료다.
